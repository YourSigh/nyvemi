## 建议的设备走查

安装独立、带内嵌 JS 的 APK → 配置 Provider 并测试连接 → 回答角色问题 → 吐槽与反馈 → 说一个之后值得问的具体事件 → 在角色设置允许通知与主动来信 → 回到桌面，等待机会性后台任务 → 点击实际通知核对角色与聊天内容 → 导出 → 在另一个安装环境导入 → 检查头像/记忆/对话。期间可用 Developer Mode 解释每次发送或跳过。

只有上述真实闭环完成，才能将 MVP 标记为全部验收完成。
