# 蛋形开场与本地声音（0.19.0）

## 首次进入

新用户直接看到简洁的 DeepSeek Key 页面，只有一个密钥输入框。其他兼容模型放在折叠的自定义设置中。保存后在真实聊天页创建同一个蛋形角色，先问颜色；无独立颜色页或角色问卷页。模型凭据缺失时回到 Key 页面，不丢角色资料。

8 个话题依次是颜色、名字、性格、关系、爱好、边界、外貌和声音。问题、用户回答和简短回应都保存为普通聊天消息；回应与下一问分成独立气泡，推荐选项在输入框上方自动换行显示。展示完成进度，不额外增加题数。DS 负责理解和自然接话，并参考近期回应避免反复复述或说“我记住了”。辅助接话失败可用本地短回应继续。

第一题复用现有主题理解、收键盘、事件锁定和渐变动画。失败可修正答案或重试；不会增加重复用户气泡。进度及待处理回答保存在本机，重启、导出和迁移后能继续。

人格最终在同一角色 ID 上完善，保留全部问答。外貌带入现有的三候选 → 选择 → 拆层/检查 → 预览 → 保存流程；不引入另一套生图 Provider。豆包 Key 在需要生图时再单独填，不借用开发者 Key。用户也可以先保留蛋，以后通过角色设置生成形象。

已有角色不重置、不重新问一遍问题。蛋是新的视觉状态，不恢复旧默认演示角色；呼吸、轻触摆动、说话和渐进裂纹由本地代码绘制。键盘弹出时仍沿用现有角色缩小与聊天区布局。

## 本地声音

Android `TextToSpeech` 原生接口，只接受中文、已安装、`isNetworkConnectionRequired=false` 的音色，不自动退回网络合成。[Android 官方说明](https://developer.android.com/reference/android/speech/tts/TextToSpeech.Engine)说明了嵌入式音色选择和语音数据安装入口。无需音频模型 Key，不记录 API token 或声音合成费用；文字对话和生图仍按各自服务计费。

新蛋角色默认启用自动朗读，以轻柔语速/音调开始，优先带女性提示的本机音色，其次使用本机可用的中文默认音色。Android 没有标准音色性别字段，不能保证任意手机都有温柔女声，也不把调音高称为音色克隆。没有合适音色时提供系统安装入口；引擎初始加载有短暂等待，真正不可用时不无限重试。某些设备的系统引擎可能需要用户安装语音包。

“设置 → 声音”可试听、选择实际音色、选轻柔/清亮/自然/低缓、开关自动朗读。声音题会保存原始描述并选择相应本机发声参数；明确选择静音时关闭朗读。已有角色保留原设定，可以自行开启声音。普通语音输入沿用按住说话/上滑取消及系统识别，系统识别是否完全离线取决于设备服务，不能与本地朗读能力混为一谈。

自动朗读只处理前台聊天中新完成的助手消息；旧历史、空回复、错误或未完成气泡不自动播放。开场的首条新问题可以直接读出。消息排队逐条播放，支持手动重听和停止；发消息、开始录音、离开聊天或进入后台时停止。进入后台恰逢引擎初始化时也会取消待播放请求。角色说话状态跟随播放队列，不做实时音素口型或声纹克隆。
