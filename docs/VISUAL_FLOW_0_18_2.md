# 形象创建流程修复（0.18.2）

此前把辅助能力变成了强制关卡：命名角色搜不到参考就不能生图，上传图还要再次点选，DS 核对出错又会中止生成或禁止拆层。本版保留 DS 整理、搜索和核对，但不再要求用户管理这些中间步骤。

## 用户流程

- 文字：描述 → 生成 3 张候选 → 选择喜欢的一张 → 制作与预览 → 保存。
- 图加描述：上传即选定，不搜索网上替代图、不重复点选上传图，生成后选候选。
- 使用原图：上传 → 整理图层，跳过候选生成与参考二次选择。
- 已有作品人物仍可自动补充公开资料；只自动采用已核对相符的公开参考。原创不搜索。公开搜索整体限时 20 秒，整理绘图描述限时 15 秒，视觉核对限时 12 秒；信号传递到请求，超时回到用户原始要求。
- DS 不可用、输出格式不合要求、找不到参考或视觉核对不可用时保留说明和开发诊断，按原始输入继续。用户决定选哪张，自动核对不再替用户否决选择。
- 换一批仍是明确的新付费动作；普通继续复用已生成图片和持久化付费响应，不自动重画。

## 可见、可恢复的制作

候选每完成一张就更新页面。选择候选后先显示原图；Seedream 返回图层响应后，每下载完成一层就更新实际计数与合成预览。服务端整理期间无法提前拿到图层，因此显示原图和真实阶段，不伪造百分比。

制作阶段包括整理图层、检查连接和遮挡、必要的双臂修复、本地整理头发和五官、最终预览。进度、原图和部分图层持久化到草稿，清理缓存时保留正在制作的素材。失败显示暂停和“继续制作”，不显示“醒来了”，也不能保存未完成制作的形象。快速离开/重进的恢复操作与制作共用锁，避免旧草稿覆盖新任务。

新制作若缺少两张独立手臂，最多自动尝试一次双臂修复；该额外请求使用豆包额度，页面在制作前说明。失败不会自动无限重试或换更贵模型，保留原图层并给出未完成说明。手工付费补救收进“高级修复”。

## 这次头发遮脸

手机原素材中，拆层模型把头发补成了没有脸部开口的完整发团。它压在脸和五官上，不只是左右手或旋转轴问题。

新增本地原图引导的遮挡修正：在脸层的有效 alpha 范围内，比较原图颜色、头发颜色和补全脸层颜色，并保护独立眼/嘴区域，去掉多余头发的 alpha。保留原画中仍应可见的刘海。只修改缓存派生层，不重画皮肤、不改原图，不额外调用模型；派生图层保存到本地并随形象导出，重复预览不重复修正。

已在用户 Android 16 手机上确认这张红衣玩偶恢复露出脸和五官，并测试说话、开心、困倦和睁闭眼预览。新形象仍保留在原草稿，未替用户覆盖此前已保存的聊天形象；聊天、记忆、人格和模型设置保留。

这是依赖原图和对齐图层的局部修正，不是完整语义分割或人工重画。发色和肤色接近、模型改变姿势/位置、大面积缺失等情况仍可能不理想，最终预览需要用户选择是否保存。本轮没有证明所有角色都能自动获得无瑕疵 Rig。

## 图片拒绝与边界

用户这次报错记录确为 HTTP 400 `InvalidParameter`，参数 `image`。旧记录只保存错误码和请求编号，没有服务端原始文本，不能断言其唯一原因，也没有盲目重发手机中结果不确定的付费请求。

Android 输入进一步规范为 EXIF 转正、sRGB 8-bit PNG、最长边不超过 2048，使用实际尺寸做像素和宽高比校验。颜色、尺寸和文件格式在设备端先处理，明确的编码/尺寸/下载等服务端拒绝文本只映射成固定诊断类型，不保存任意响应文字或密钥。[官方图像 API 文档](https://docs.volcengine.com/docs/ark/image-generation-api)支持拆层传入单张 PNG/JPEG；应用保留更严格的本地文件限制。

不能保证服务商永远不再返回 400；本版保证辅助错误不会截断有效的生图请求、已有成果能保留、请求不确定时不会自动重复扣费，并让下一次明确图片拒绝更容易定位。
