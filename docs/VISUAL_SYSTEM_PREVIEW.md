# Nyvemi 视觉系统：第一轮预览

## 范围与现状

本轮只做主题视觉与初生角色的设计预览，不修改聊天模型、记忆、主动消息、角色 Rig 或创建业务。遵循“先确认设计方向，再逐步实施”的要求，现有聊天页与默认粉白主题暂不替换。

检查结果：原先 Palette 只有九个基础颜色；AI 气泡和推荐回复共用 tint、用户气泡与输入共用 paper。圆角胶囊重复，主要层级靠留白区分。初生蛋为珠光金线花饰图集，装饰压过角色本身。

## 具体调整

- 用语义 Token 区分背景、卡片、正文、次级文字、边框、主色、强调、AI/用户气泡、推荐项、输入、禁用和按压/焦点反馈。主色不在 Token 层被暗中调整。
- AI 气泡采用近纸色背景和细边框；用户气泡保留更明显的主题底色。推荐项用 12px 圆角的描边小卡片，输入框 16px、消息 18px，避免全是胶囊。
- 初生形象改为日系插画“月胚之茧”：闭眼侧身抱膝、银白淡紫短发、乳白色披覆，细光丝只包裹主体，不形成实体蛋壳。不改变用户后续生成角色的渲染路径。
- 主题预览含当前进度、角色展示、消息、三种其它主题按钮、输入焦点、发送按钮的禁用/可用外观，以及旧样式对比。输入不发消息，切换不写入设置，不调用模型。
- 设置 → 换颜色 → 看看四种主题。也可用 `nyvemi://theme-preview/sakura`、`moonlight`、`mint`、`nebula` 直接预览。

## 待补齐的指定 HEX（必要输入）

用户要求四套指定 HEX，但本条消息只附角色参考图，未附色值。因此 `visual-presets.ts` 只定义四套语义与名称，预览临时沿用现有默认粉白/原有生成器的紫、绿、深蓝，没有自行编造新的主色。它们尚不是最终四套色板，不会应用到正式页面。

请补齐 Sakura Mist、Moonlight、Mist Green、Nebula 的 HEX；至少需要各主题主色、页面背景、卡片、正文，若已有完整色板应直接使用。最终会保留指定主色，通过背景/前景配对校验可读性；如指定色值导致对比度不足，应呈现问题后确认，而非悄悄改色。

## 确认后接入方式

默认使用 Sakura Mist。开场当前已是粉白时只提供另外三套主题按钮，不新增配置步骤。按钮本地切换，无须 API Key，也不消耗模型额度。自由回答继续由现有 ThemeService 理解。

聊天换色仍由模型输出语义，而不是随意生成 HEX：常规请求匹配四套主题配方；其它色系沿用低/中饱和、明暗可读性约束，并统一经过相同语义 Token。继续复用现有收键盘、事件锁定、左上到右下揭幕动画，不另造换色流程。待色板和视觉方向确认后，再把预览使用的 Token 与初生角色接入现有聊天组件，不重写聊天业务。
