# Nyvemi 视觉系统 · 0.19.2

## 范围和检查结果

只调整主题、聊天组件的视觉与初生角色；复用现有聊天/创建/角色渲染业务，不修改模型、记忆或主动消息算法。

原 Palette 只有九个基础颜色，AI 气泡和推荐项共用 tint，用户气泡与输入框共用 paper。珠光蛋的装饰比角色本身醒目。这一轮以语义 Token 拆分层级，使用月胚之茧替换初生蛋的展示；存储里的 egg 标记保持兼容。

## 四套色板

`src/theme/brand-colors.ts` 保存用户提供的 32 个原始 HEX：背景、卡片、主色、按钮强调、浅底、用户气泡、辅助色和正文。不得为修复对比度暗改这些值。默认是樱雾 Sakura Mist。

`design-tokens.ts` 管理背景、卡片、主色、按钮强调、正文、次级文字、边框、AI/用户气泡、推荐项、输入框、禁用、按压和焦点反馈。AI 气泡为近纸色配细描边，用户气泡保留指定主题色，推荐项采用独立白/暗底描边小卡片。圆角分别为卡片 20、消息 18、推荐项 12、输入 16、按钮 14。

柔和的品牌主色不适合直接做小号文字。另从品牌色与正文色推导可读的文字强调色，主色本身保留。按钮使用指定强调色，自动配对深/浅前景文字；按压状态也保持文字对比度。未提供的边框、次级文字、错误色由统一规则补齐。自动测试检查四套所有阅读表面与按钮前景对比度（正常文字至少 4.5:1）。

## 开场和聊天换色

首次使用默认粉白，颜色题显示“月胚 · 淡紫 / 薄荷 · 清绿 / 星夜 · 深色”三个按钮。命名主题本地立即理解，无须 API Key，不请求模型。切换浅色预设会正确退出之前的深色模式。

用户自由描述颜色时继续使用现有 ThemeService：明确颜色本地理解，抽象感觉才调用模型；模型只返回颜色/氛围语义，不输出 HEX。粉、紫、薄荷和深蓝/紫映射到同一套品牌配方；其它色系由原有低/中饱和、明暗和可读性约束生成，再使用同一组组件 Token。不会接受模型任意输出的杂乱色板。

继续复用现有收键盘、事件锁定和左上到右下主题揭幕动画。ThemeProvider 一次更新整组 Palette，导航、表单、消息、推荐项和输入同步刷新。

## 初生角色

日系插画“月胚之茧”：侧身抱膝、闭眼、银白淡紫发丝、乳白色披覆、轻薄光茧。保留轻微悬浮和触碰反馈；思考/说话改变光晕强度，不声称这是新的 Live2D Rig。已有用户角色资产与 Mesh Runtime 不变，角色区原有约 1/3 屏幕与键盘收缩行为保留。

素材与完整生成提示词见 [MOON_COCOON_ARTWORK.md](MOON_COCOON_ARTWORK.md)。

## 可切换预览

设置 → 换颜色 → 看看四种主题。也可打开 `nyvemi://theme-preview/sakura`、`moonlight`、`mint`、`nebula`。原生页面展示同一素材与 Token，可切四主题、查看旧蛋和旧气泡样式、体验输入焦点。它不请求模型、不发送聊天消息、不写入主题或角色进度；正式应用主题仍走原有换色入口。

本轮停留在主题和初生角色范围，供确认方向后继续细化；未顺带重构其它功能页面，未扩展角色 Rig 能力。
