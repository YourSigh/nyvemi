# 0.15.0 UI 与首次使用简化

本轮复用聊天、角色 Runtime、主题动画与键盘控制，没有重建这些链路。

## 页面调整

| 页面                   | 默认展示                               | 按需展开 / 滚动                                                    |
| ---------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| 首次颜色选择           | 短说明、输入、四个短选项、一个主按钮   | 跳过和恢复备份为文字操作；无 Key 可用的本地解析保留                |
| 聊天模型               | DeepSeek 与一个 Key 输入框             | 自定义地址 / 模型、恢复预设；保存现有自定义配置不会被默认值覆盖    |
| 画图与识图             | 聊天模型识图、豆包 Key、聊天画图开关   | 自定义识图、生图地址 / 模型、后台自主生图权限                      |
| 角色访谈               | 当前问题、所有推荐选项、进度           | 访谈历史自然滚动；完成后先展示简短设定，完整回答折叠且可修改       |
| 形象创建               | 描述、创建方式、豆包 Key、生成按钮     | 已有模型导入、自定义参数折叠；可跳过形象进入聊天                   |
| 候选选择               | 三张图同排，先选中，再确认拆层         | 付费重新生成独立操作；不因点选候选立刻扣费                         |
| 形象预览               | 根据窗口限制高度，动作使用文字按钮     | 编辑 / 重新选择保留                                                |
| 设置首页               | 模型、画图与识图、角色形象、颜色、通知 | 来信偏好、记忆、经历、插件、快捷方式、用量、备份、高级功能归入更多 |
| 用量                   | 时间范围与费用汇总                     | 单价配置、请求明细折叠                                             |
| 插件                   | 自主学习权限与已安装能力               | 地址 / 文件安装折叠，权限确认保留                                  |
| 备份恢复               | 导出、选择文件、必要隐私提示           | 格式详情折叠，已有角色不能静默覆盖                                 |
| 记忆 / 经历 / 开发信息 | 真实历史数据                           | 这些列表按真实内容滚动，不截断数据来强行凑一屏                     |

公共表单减少标题、卡片和安全区额外留白。实际内容高度大于视口时才允许手势滚动；键盘展开时保留滚动与输入框避让。未通过隐藏溢出内容来伪造“一屏”。文字按钮保留 44dp 触摸高度，主按钮和输入框保留 48dp 下限。小屏、大字体和高级配置展开仍可能需要滚动。

## 模型和角色边界

- 正常用户默认 DeepSeek + Seedream，仅填自己的 Key。Mock 继续通过测试注入，不作为普通用户的生成入口。
- 现有自定义模型配置保留；不同服务地址不能误复用 Key。
- 填豆包 Key 后默认开启聊天画图；后台自主生图仍须单独开启，保存不调用 API。
- 移除预设角色创建按钮、示例人格自动补充和内置模型自动升级。生成新角色不再以固定人格为样本。
- 原形象在 `dev-assets/characters` 留存，Metro blockList 阻止导入。已有用户角色不被删除或重命名。
- Release 通过 `npm run android:release` 先清理 App 构建输出，避免已移除的 React Native 资源被增量打包再次带入。
- `scripts/check-release.cjs <APK>` 检查解压条目、素材内容哈希、预设名称标记和本地开发密钥，避免只靠文件名判断是否打包。

## 验证范围

自动用例覆盖：内容适配 / 键盘时滚动、隐藏高级输入控件、新用户仅填 Key 保存预设、旧自定义配置保留、豆包密钥绑定、默认后台画图关闭、候选点选与付费拆层分离、生产源不再依赖预设角色。

执行 lint、TypeScript、离线自动测试、Android Kotlin 单元测试、Debug 与包含 JavaScript 的 Release 构建。按用户要求不做真机 / 模拟器自测，也不为 UI 改动调用付费模型。各机型的字体尺寸、输入法与实际观感仍需安装验收；构建成功不代表已经完成设备视觉验证。

验证结果：304 项离线自动测试通过，11 项可选真实 API 测试跳过；lint / typecheck、Android Debug / Release、Kotlin 单元测试任务通过。Release 清理前的检查实际发现增量产物残留旧角色资源，清理重建后再次检查通过，发布脚本已固定执行清理和检查。
