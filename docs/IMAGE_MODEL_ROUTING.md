# 生图与拆层模型分流（0.17.0）

## 使用

普通用户只需自己的豆包 / 火山方舟 Key。默认配置：

| 工作                           | 模型                               |
| ------------------------------ | ---------------------------------- |
| 角色候选、聊天生图             | `doubao-seedream-5-0-pro-260628`   |
| 图层拆分、明确确认后的身体修复 | `doubao-seedream-5-0-flash-260915` |

角色形象或图片设置的折叠选项里可切换“省钱组合”与“Pro生图 + Pro拆层”，也可自填模型或 Endpoint ID。Flash 要在自己的方舟账户开通；不支持或失败时显示错误，不会悄悄切到 Pro 重试。保存设置本身不调用模型。后台自主生图仍是独立开关。

旧版未标记、官方地址、Pro/Pro 默认配置会迁移到 Pro/Flash；自定义地址/模型以及新版本明确保存的 Pro/Pro 不自动迁移。已有形象、人物、记忆和聊天不被重建。

## 复用与计费边界

之前缓存把生图和拆层模型绑在一起。现在更换拆层模型仍可复用原候选、参考核对和聊天生图；只在明确执行拆层时使用新的拆层模型。单独更换生图模型也不会使相同输入的拆层失效。

旧缓存按对应操作迁移，保留原下载文件名和已付费响应。部分下载失败可以继续下载；状态不确定的请求继续阻止自动重发。Prompt 的措辞改进只影响新请求，不会使旧拆层凭据失效，也不会自动花钱“升级”素材。已完成形象无需为配置变化重新付费。

一条 HTTP 拆层请求可以返回一张底图和多张透明层，按实际输出图片计费，不能当作“只画一张”。服务最多输出底图加 16 层；请求六组角色部件不构成服务端严格的数量或质量保证。IPM 的额度预占也不等于最终计费张数。

截至 2026-11-03 的[官方价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh&redirect=1)：Flash 输出 ¥0.12/张；Pro 拆层每张 ≤261 万像素 ¥0.15，超过为 ¥0.30；Pro 普通生图对应为 ¥0.30/¥0.60。输入参考图免费，实际以账户账单为准。[两种模型均支持原生图层拆分](https://docs.volcengine.com/docs/ark/seedream-5-0-pro?lang=zh)。

因此省的是拆层单价，而不是把生图换成便宜模型或偷偷降低原画分辨率。对复杂角色，Flash 与 Pro 的分层质量仍可能不同；本次没有同 Prompt 的 Pro 对照，不能声称完全等效。

## 真实验证

复用了开发目录中已有的简化立绘，没有重新请求原画，也没有把测试角色打包进 App。本任务 Flash 请求计数固定上限为 2，不重置此前任务的预算。普通 `npm test` 不会读取 `.env` 发付费请求。

| 步骤                         | 真实结果                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------- |
| 原 Prompt，Flash 拆层        | 成功返回底图 + 6 层；身体含袖子，手臂层却补成裸臂，静态重组有多余裸露皮肤，不通过 |
| 明确袖子与手臂归属，再拆一次 | 成功返回底图 + 6 层；衣服、五官及角色身份保持，可见裸臂重复问题消失               |
| 重跑第二轮验证               | 使用完整 SQLite 付费缓存，新增生图/拆层 POST 为 0                                 |

两个响应均报告 `generated_images=7`，合计 14 张。按现价估算 Flash 图片输出费用 **¥1.68**，另有两次 DS 静态识图核对；这不是账户实际扣款查询。每轮 7 张输出估算 ¥0.84；若 Pro 返回完全相同尺寸与数量，按这些输出的像素档位估算 ¥1.20，约省 30%，但 Pro 实际返回数与尺寸可能不同。

检查了必要角色层、实际透明像素、原生像素坐标、按 z 重组以及缓存重放。改进后的 DS 静态核对为 `identity=match`、`layersUsable=true`，**hiddenAreaQuality=uncertain**：颈部和肩臂遮挡处无法充分确认。肉眼核对也没有把这项不确定性抹掉。第一轮 DS 还曾把按要求留空的脸层误判为缺失五官，因此它是辅助观察，不是绝对质量裁判。

Prompt 改进适用于所有用户角色：袖子随手臂拆分、身体层移除手臂与袖子、禁止新增裸露皮肤、补全被遮挡躯干和肩颈根部、保留覆盖边。坐标优先使用服务返回的原生像素框，避免 0–1000 舍入产生的小偏差；异常框保留响应并停止，不花钱盲重试。

开发机证据（忽略目录，不入包）：

- `artifacts/live-flash-split/result.json`：第一轮失败原因。
- `artifacts/live-flash-split-refined/result.json`：第二轮素材、usage、DS 观察。
- 两目录的 `inspection/composite.png`：静态重组与单层预览。
- `artifacts/live-flash-split/budget.json`：本任务累计 2/2 次预算。

显式验证命令为 `node scripts/test-live-flash.cjs --allow-flash-split --refined`。现有预算已耗尽，保留缓存时只重放；不得清预算冒充同一轮测试。测试原画路径仅供开发机使用，缺少该文件会停止，不会付费补画。
