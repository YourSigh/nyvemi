# 参考音色（第一版）

聊天里说「我希望你的声音跟流萤一样」，会直接查参考声。找到的公开录音先保存在角色的声音设置里供试听；**公开可听不等于有权换声**。有权使用时点一次「设为参考音色」，也可导入自己的 PCM16 WAV（最长 30 秒、3 MiB）。之后使用这个角色的设置，不再到网上重新找。音频留在 App 私有目录，不随角色包导出。

启用消息语音后，默认由 DeepSeek 官方 TTS 的 Stella 或 Tide 朗读。音高、厚薄、明暗、贴耳感、空气感、语速、音量均在手机对返回的 WAV 本地处理，**不用换声服务**。启用参考音色且服务可用时才会把合成 WAV、参考 WAV 交给换声服务。参考服务失败时仍播放同一次合成的 DeepSeek 语音；只有 DeepSeek 本身不可用时才回退安卓系统语音。DeepSeek Key 只用于官方地址，非官方 Provider 的 Key 不会自动转发。

只为确认发出的气泡准备语音。首段较短，播第一段时就准备下一段；不等整条音频完成，也不是逐帧实时变声。没有做真机移动网络延迟基准；当前 OpenVoice 接口仍按段传 WAV。

## Mac 和 Android 联调

1. 在 Mac 上启动 OpenVoice V2（`127.0.0.1:8000`）和 [独立配套服务](../tools/voice-companion/README.md)（`127.0.0.1:4319`）。
2. 专用 Android 开发设备用 `adb -s <serial> reverse tcp:4319 tcp:4319`；在「声音 → 连接换声服务」设置 `http://127.0.0.1:4319` 和独立令牌。
3. 在 App 的 Provider 设置使用官方 DeepSeek 和自己的 Key。换声模型不可用时会播放普通 DeepSeek 朗读（仍需 TTS 请求），不会重复合成。

正式版只接受 HTTPS 配套服务；需要离开 Mac 也能换声时应另设带鉴权的 HTTPS 网关。没有自动部署公网端口。

## 可选本机换声（实验版）

「声音 → 参考音色」新增本机模型包导入和独立开关，默认关闭。模型包约 117 MiB，导入后约占 125 MiB 私有存储，不随基础 APK 分发。只接受校验通过的官方 OpenVoice V2 自导出包，导入不会自动启用；打开开关后，已授权参考 WAV 和换声计算都留在手机。DeepSeek 仍负责生成原始语音，本机换声不等于离线 TTS。

本机模式失败会保留同一次 DeepSeek 原声，不偷偷切换远程服务上传参考音频，不重复合成。关掉本机开关才使用原有明确配置的远程换声模式。单段源语音最多 10 秒、参考 WAV 最多 30 秒；停止会取消原生推理并丢弃迟到结果。

Redmi K80 Pro 已验证真正手机 WAV→WAV：4 秒音频转换约 2.0–2.1 秒，前处理约 0.24 秒，进程峰值约 449 MiB。使用合成参考声，未作音色相似度保证；自实现重采样不同于 librosa soxr，独立水印阶段尚未移植。模型来源、复现和验收边界见 [Android OpenVoice 说明](../tools/openvoice-android/README.md)。模型包本次未上传分发，正式 App 未被验收包覆盖。
