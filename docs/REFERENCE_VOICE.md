# 参考音色（第一版）

聊天里说「想要流萤的声音」或「我希望你的声音跟流萤一样」，模型未准备时会先提供明确的模型下载入口，用户点击后才联网，不改动原声。模型就绪后会直接从手机查找同角色中文候选，不再要求连接 Mac 服务。当前主路径支持 BWIKI 原神/星铁准确中文角色名；页面无音频时，仅对已验证名称使用原 Web 的同角色中文归档后备。选择下载试听后，公开录音才保存在角色的候选声音里；**公开可听不等于有权换声**。有权使用时点一次「设为参考音色」，可先试听原录音，明确有权使用后还可「试听本机换声（不应用）」，确认转换效果再应用同一段录音；也可导入自己的 PCM16 WAV（最长 30 秒、3 MiB）。之后使用这个角色的设置，不再到网上重新找。音频留在 App 私有目录，不随角色包导出。

启用消息语音后，默认由 DeepSeek 官方 TTS 的 Stella 或 Tide 朗读。音高、厚薄、明暗、贴耳感、空气感、语速、音量均在手机对返回的 WAV 本地处理，**不用换声服务**。参考音色在本机模式下由手机处理，不发送参考音频；仅在明确关闭本机模式并配置远程换声服务时，才会把合成 WAV、参考 WAV 交给该服务。参考服务失败时仍播放同一次合成的 DeepSeek 语音；只有 DeepSeek 本身不可用时才回退安卓系统语音。DeepSeek Key 只用于官方地址，非官方 Provider 的 Key 不会自动转发。

只为确认发出的气泡准备语音。首段较短，播第一段时就准备下一段；不等整条音频完成，也不是逐帧实时变声。没有做真机移动网络延迟基准；当前 OpenVoice 接口仍按段传 WAV。

## 可选的旧配套服务联调

1. 在 Mac 上启动 OpenVoice V2（`127.0.0.1:8000`）和 [独立配套服务](../tools/voice-companion/README.md)（`127.0.0.1:4319`）。
2. 专用 Android 开发设备用 `adb -s <serial> reverse tcp:4319 tcp:4319`；在「声音 → 连接换声服务」设置 `http://127.0.0.1:4319` 和独立令牌。
3. 在 App 的 Provider 设置使用官方 DeepSeek 和自己的 Key。换声模型不可用时会播放普通 DeepSeek 朗读（仍需 TTS 请求），不会重复合成。

正式版只接受 HTTPS 配套服务；需要离开 Mac 也能换声时应另设带鉴权的 HTTPS 网关。没有自动部署公网端口。

## 可选本机换声（实验版）

「声音 → 参考音色」提供本机模型下载、手动 ZIP 导入兜底和独立开关，默认关闭。从 0.20.19 起，标准 ARM64 APK 不再内置模型，也不含 Qwen 的 761 MB 权重。模型包为 122,874,105 bytes（117.18 MiB），只在明确点击后下载；暂停保留私有临时文件供续传，下载后验证固定 SHA-256、包内容及运行兼容性。已有成功导入的模型继续使用，不因更新重新下载。安装后的模型另占约 125 MiB 私有存储，下载临时包期间还需约 117 MiB 空间。导入或下载均不会自动启用或选择参考声音；DeepSeek 仍负责生成原始语音，本机换声不等于离线 TTS。

本机模式失败会保留同一次 DeepSeek 原声，不偷偷切换远程服务上传参考音频，不重复合成。关掉本机开关才使用原有明确配置的远程换声模式。源语音最多 30 秒，超过 10 秒时按约 8 秒低能量边界分段转换；参考 WAV 最多 30 秒；停止会取消原生推理并丢弃迟到结果。

Redmi K80 Pro 已验证真正手机 WAV→WAV：4 秒音频转换约 2.0–2.1 秒，前处理约 0.24 秒，进程峰值约 449 MiB。使用合成参考声，未作音色相似度保证；自实现重采样不同于 librosa soxr，独立水印阶段尚未移植。模型来源、复现和验收边界见 [Android OpenVoice 说明](../tools/openvoice-android/README.md)。下载包附带原始 MIT 许可及来源说明。正式 App 未被验收包覆盖。

## 0.20.18 聊天换声修复

- 「想要流萤的声音」等明确请求在本机模型就绪时自动查找一次，卡片展示候选名字与来源；模型未就绪则点准备后继续同一请求。
- 「下载并试听」播放的是公开原录音，不是转换结果，也不会应用。公开可听不代表已获换声授权。
- 对有权使用的同一候选，可手动点击转换试听：一次 DeepSeek 合成 → 本机转换 → 只播放转换结果。失败/取消不播放原声或系统声冒充成功，不修改开关或角色参考。
- 明确「设为参考音色」后才保存同一文件和来源、开启本机引擎；后续相同角色请求复用已确认的录音，不反复查找。
- 声音设置主按钮改为「试听当前声音」，保留当前参考，而不是隐式忽略参考。聊天转换失败仍可回退，但会明确提示未完成换声。
- PCM16 WAV 导入与原生都接受 8–96 kHz。较长源音频分段处理，不再因为单段超过 10 秒就直接回原声。

来源可用性与模型是否能运行是两回事。公开站点无法读取、页面无中文音频、或未找到对应角色时会明确失败，不替换成其他角色/语种。当前并非全网任意角色搜索，亦未提供角色声音授权或相似度保证。

真机验收（隔离测试包，2026-11-17）：流萤同角色 Fandom 中文归档、卡芙卡 BWIKI 中文录音都在 Redmi 实际查找、下载、解码及原录音完整播放成功。明确标记的授权合成候选完成了应用前本机转换试听（开关仍关闭、尚未应用）、应用同一 id、重启保留、真实聊天播放队列使用该参考；不存在角色查询没有改变已应用参考。TTS 使用缓存，没有新增付费合成。公开角色录音只测原录音试听，没有代用户确认换声权利或宣称角色音色相似度。长于 10 秒的分段覆盖已做单测，本轮未另做长音频真机音质验收。
