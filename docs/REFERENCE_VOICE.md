# 参考音色（第一版）

聊天里说「我希望你的声音跟流萤一样」，会直接查参考声。找到的公开录音先保存在角色的声音设置里供试听；**公开可听不等于有权换声**。有权使用时点一次「设为参考音色」，也可导入自己的 PCM16 WAV（最长 30 秒、3 MiB）。之后使用这个角色的设置，不再到网上重新找。音频留在 App 私有目录，不随角色包导出。

开启后，由 DeepSeek 官方 TTS 的 Stella 朗读，再把合成与参考 WAV 交给用户配置的换声服务。DeepSeek Key 仅用于官方地址，不发给换声服务。非官方 Provider 不会自动复用其密钥。新模式失败会回退到现有 Qwen 或系统本机声音，文字仍然正常。没选参考声时保留现有行为。

只为确认发出的气泡准备语音。首段较短，播第一段时就准备下一段；不等整条音频完成，也不是逐帧实时变声。没有做真机移动网络延迟基准；当前 OpenVoice 接口仍按段传 WAV。

## Mac 和 Android 联调

1. 在 Mac 上启动 OpenVoice V2（`127.0.0.1:8000`）和 [独立配套服务](../tools/voice-companion/README.md)（`127.0.0.1:4319`）。
2. 专用 Android 开发设备用 `adb -s <serial> reverse tcp:4319 tcp:4319`；在「声音 → 连接换声服务」设置 `http://127.0.0.1:4319` 和独立令牌。
3. 在 App 的 Provider 设置使用官方 DeepSeek 和自己的 Key。换声模型不可用时会在发起付费 TTS 前回退。

正式版只接受 HTTPS 配套服务；需要离开 Mac 也能换声时应另设带鉴权的 HTTPS 网关。没有自动部署公网端口。
